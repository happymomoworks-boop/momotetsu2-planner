# 全面改修の報告（2026-11-12）

## 1. 変更内容

- **デザイン**：ゲーム画面の作りに寄せた。クリーム地＋茶色の縁のウィンドウ、金の見出し帯、青緑の決定ボタン、ピンクの目的地の帯、選択中はオレンジ。種類の色はマスに合わせた（物件・イベント＝青、注意＝赤、カード＝黄、ヒーロー＝ピンク）。東＝青、西＝赤。ライト／ダーク両対応。
- **公式素材**（許可済み・`img/official/` の25点）：ロゴ、東西のキャラクター、ボンビー9体、各画面の見出しの飾り。公式サイト「あそびかた」ページから取得。ゲームの画面写真は使っていない。
- **ヘッダーの「非公式」表記**：持ち主の指示で外した。出典欄の素材の説明、manifest の名前、コピー文面の「（非公式）」は残っている。
- **アイコン・ホーム画面**：持ち主が用意したアイコン画像（`icons/source-1254.png`）から favicon・apple-touch-icon 180px・192/512px を生成。`manifest.webmanifest` あり。
- **公式サイトのデザイン部品**（追加8点）：空と雲のヘッダー、富士山と名所の帯、桃の見出しマーク、東西のスタンプ、星の背景。
- **構成**：`js/verify.js`（照合の記録とカードの効果）、`tools/e2e_test.py`（操作テスト）を追加。`tools/build_single.py` は画像も埋め込む。

## 1-2. 盤面とマス数（2026-11-12 追加）

- 公式サイト「まるっと全駅！マップ」から、全駅（東627・西522）の駅名・よみ・盤面上の位置・種類・物件名を取り込んだ（`js/stations.js`、`tools/build_stations.py`）。
- 距離は実際の地理（km）をやめ、盤面のマス数（たて＋よこ）にした。例：東京→仙台 約41マス、大阪→高松 約30マス。線路のつながりは公式にも無いため、回り道の分は入っていない。
- 地図は公式の盤面と同じ配置。全駅を小さなマスで描き、物件駅をタップすると物件一覧が出る。駅名はひらがなのよみでも探せる。
- 配色は公式サイトのトップ（東＝青、西＝赤、ボタン＝ピンク、文字＝濃い茶）。
- レスポンシブ：横スクロールで逃がしていた所（年の路線・チップ・年表）を折り返しに。タブレットは一覧2列、PCはプランを「入力｜結果」の2列。
- テスト：81項目すべて合格。320・360・375・390・412・430・768・1024・1280px×ライト／ダークで、はみ出し・文字切れ・ボタンの重なりなし。

## 2. 追加した機能（すべて結果に反映される）

| 機能 | 何が変わるか |
|---|---|
| いまの月 | 月のタスク（決算・8月の青マス・冬の赤マスなど）が加わる。止まらない場所が月で絞られる（軽井沢7月、徳島8月、岸和田9月、網走12〜2月） |
| プレイ人数 | 宮本武蔵・長浜・西陣でもらえるカードの表示が切り替わる |
| 作戦（バランス／物件・ヒーロー重視／カード重視） | 寄る駅の点数と、やることの順位が変わる |
| 手持ちカードの登録（12種＋枚数） | 周遊カードの有無で周遊駅・ダビング駅・売り場の価値が変わる。枚数で夕張（4枚以上）・門司港（5枚以上）の注意が出る |
| 最優先の表示 | やることの1位と、その区間で寄るべき駅を画面上部に出す |
| やること／避けることの区別 | プラン画面で分けて表示 |
| 寄る駅の並べ方 | 行ったり来たりしない順に並べ替え |
| 年別のチェックリスト | 終えたやることにチェック。年ごとに保存 |
| 検索・絞り込み | 地図（駅名）、ヒーロー（名前・駅・効果／いまの時期／SS・S／いま独占できる）、物件（駅・物件名／元が早く取れる／所持金で買える）、カード（名前・効果） |
| 物件の「元が取れるまで」 | 価格÷年間収益を表示 |
| 入れ替え・作戦のコピー | いまいる駅と目的地の入れ替え、プランの文面コピー |
| 保存と復元 | JSON ファイルに書き出し・読み込み・全消去 |
| 出典と確認状況 | 項目ごとに確認済み／推定／未確認と出典リンクを表示 |
