# 桃鉄2 攻略プランナー（非公式）

桃太郎電鉄2（東日本編＋西日本編）で、プレイ年数・いまいる駅・目的地を入れると、通り道で寄る駅と年別プランを出すWebアプリです。

- 使う：`index.html` をブラウザで開く
- 開発を続ける：このフォルダを Claude Code で開く（引き継ぎメモは `CLAUDE.md`）
- 仕様とデータの全体：`docs/review.md`

攻略情報は Game8・ファミ通.com などの記事（2025年11月〜2026年1月更新）をもとにしています。ゲームの画面・キャラクター・ロゴの画像は使っていません。地図の輪郭は地球地図日本（国土地理院）のデータを加工したものです。
